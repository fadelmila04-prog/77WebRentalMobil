# 77RentCar - Responsive Landing Page & Booking Web App

Aplikasi web modern untuk penyewaan mobil **77RentCar** dengan antarmuka bertema *dark mode* dan aksen *electric blue*. Dibuat menggunakan React, Vite, dan Vanilla CSS tanpa dependencies backend tambahan.

---

## 🚀 Fitur Utama

- **SPA Landing Page**: Struktur lengkap mulai dari Hero Section, Tentang Kami, Katalog Unit Mobil, Statistik, hingga Alamat Kontak & Google Maps.
- **Form Modal Booking**: Modal dinamis yang menampilkan form pemesanan secara langsung saat tombol *BOOKING NOW* atau *Sewa Sekarang* diklik.
- **Integrasi WhatsApp Otomatis**: Membuat pesan terformat khusus ke nomor WhatsApp resmi 77RentCar berdasarkan isi form booking.
- **Floating WhatsApp Button**: Button melayang di sudut kanan bawah untuk akses cepat layanan pelanggan via WhatsApp.
- **Desain Responsive**: Optimasi tampilan penuh untuk perangkat Desktop, Tablet, dan Mobile.
